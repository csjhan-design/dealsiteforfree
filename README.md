🧺 智桃團購站 | 婆媽省錢團購好鄰居

智桃團購站 是一個專為「婆婆媽媽與家庭客群」量身打造的純前端團購商品展示型錄網站。採用溫暖討喜的柿紅與暖米杏配色，搭配全站放大字體、高對比排版與直覺的「現省金額」標示，讓長輩與媽媽們不需瞇眼就能輕鬆瀏覽當期團購好物。

✨ 網站核心特色

1. 👵 婆媽友善介面設計 (Mom-Friendly UI)

全站大字體與高清晰度：引入 Google Fonts Noto Sans TC 繁體中文黑體，從導覽列、分類按鈕到商品詳情彈窗全面放大字級。

直覺「現省金額」自動計算：只要填寫市價（oldPrice）與團購價（price），系統會自動計算差額並於商品卡右上角及詳情內頁醒目標示 「現省 $XXX」。

貼心共鳴亮點標籤：支援在商品標題上方顯示專屬推薦語（如：👵 初一十五拜拜首選、🔥 煎魚不破皮・輕巧不重手）。

2. 📱 豐富的前台展示與篩選體驗

支援觸控滑動的主視覺輪播 (Hero Carousel)：首頁頂部內建多圖自動輪播，在手機上可直接左右滑動切換。

團長阿桃廣播站：獨立的新聞公告滾動區塊，方便置頂最新到貨、補貨或省錢快報。

限時結單倒數計時器：自動計算距離收單截止日的「天、時、分、秒」，營造團購搶購熱度（時間到自動隱藏）。

即時搜尋、分類與排序：

點擊分類膠囊按鈕（如：🍎 產地鮮果、🍳 廚房神隊友、🥟 快速上菜 等）快速過濾。

支援關鍵字即時搜尋（同時比對商品名稱、分類與內文介紹）及價格高低排序。

放大字體詳情彈窗 (Responsive Modal)：點擊任一商品卡片即可彈出大圖與完整規格介紹；電腦版為居中視窗，手機版自動轉為符合單手操作的底部滑出抽屜（Bottom Sheet）。

3. 🎨 動態主題色引擎與零後台負擔

一鍵變換全站主視覺顏色：內建 JavaScript 色彩演算法，只需更改 brandColor 一個 HEX 色碼，系統即自動運算出 Hover 深色與背景淺色並套用至全站。

純前端單一檔案架構：所有 HTML、CSS 與 JavaScript 皆封裝於單一 index.html 中，無需資料庫或伺服器後台，載入速度極快且零維護成本。

🛠️ 技術架構

結構與邏輯：HTML5 + Vanilla JavaScript (ES6+)

樣式框架：Tailwind CSS (透過 CDN 載入，結合 CSS Variables 動態主題)

圖示庫：FontAwesome 6.6.0 (包含 LINE、Facebook、Instagram、Threads 等社群圖示)

字型：Google Fonts (Noto Sans TC 繁體中文黑體 + Inter)

📝 內容修改指南（如何自己改文字、換商品？）

本網站的所有資料皆集中整理在 index.html 檔案底部的 <script> 區塊中（搜尋 const appState = { 即可找到）。您只需要用記事本或 VS Code 修改裡面的文字，存檔後重新整理網頁即可生效！

1. 修改網站基本資訊、主色調與結單倒數 (siteConfig)

找到 siteConfig 區塊，您可以自由修改以下欄位：

siteConfig: {
    title: '智桃團購站',                        // 網站名稱 (導覽列、頁尾、網頁標題會同步更新)
    desc: '阿桃姐與鄰居媽媽們的省錢秘密基地...', // 頁尾品牌介紹文字
    slogan: '買菜順便帶・婆媽省錢好鄰居',         // 頁尾金色標語
    brandColor: '#e03e2d',                     // 全站主視覺顏色 (填入色碼即自動變換全站配色)
    logoUrl: '',                               // 品牌 Logo 圖片網址 (留空則顯示預設菜籃圖示)
    countdownEnd: '2026-12-31T23:59:59',       // 結單倒數截止時間 (格式：YYYY-MM-DDTHH:mm:ss，留空則隱藏倒數條)
    
    // 聯絡資訊 (若某個欄位不想顯示，將內容清空為 '' 即可自動隱藏)
    companyName: '智桃團購站',
    taxId: '88889999',
    phone: '03-456-7890',
    mobile: '0912-345-678',
    email: 'service@zhitao-groupbuy.com',
    
    // 社群連結 (留空 '' 則前台不顯示該圖示)
    socialLine: 'https://line.me/ti/p/...',
    socialFb: 'https://facebook.com/...',
    socialIg: 'https://instagram.com/...',
    socialThreads: ''
}


2. 修改首頁輪播大圖 (heroBanners)

在 siteConfig.heroBanners 陣列中，可以設定首頁上方的輪播圖片與標題：

heroBanners: [
    {
        img: '圖片網址 (建議尺寸 1200x800)',
        title: '🍎 產地直送！當季鮮果整箱搬最划算',
        desc: '果園新鮮現採直送到家，顆顆飽滿香甜多汁，拜拜送禮或全家人飯後吃都超棒！'
    },
    // 可自由增減輪播項目...
]


3. 修改「團長阿桃廣播站」最新消息 (news)

在 news 陣列中，可以隨時新增或刪除廣播訊息：

news: [
    { id: 'n1', content: '🍎 【新鮮到貨】日本青森蜜富士大蘋果到港囉！', date: '今日最新' },
    { id: 'n2', content: '🍲 【晚餐救星】老字號紅燒半筋半肉牛肉湯補貨到！', date: '熱銷通報' }
]


4. 新增或修改團購商品 (products)

在 products 陣列中，每一個 { ... } 代表一項商品。複製其中一段即可新增商品，而且分類按鈕會根據您填寫的 category 自動生成！

{
    id: 'p1',                                           // 商品唯一編號 (請勿重複，如 p1, p2, p9...)
    title: '日本青森頂級蜜富士大蘋果 (家庭分享箱)',        // 商品名稱
    category: '🍎 產地鮮果',                             // 商品分類 (網站會自動抓取所有分類做成篩選按鈕)
    specs: '6顆精裝禮盒, 12顆家庭大箱裝 (最划算)',         // 規格組合 (多個規格請用半形逗號 , 分隔)
    price: 890,                                         // 團購批發價 (純數字)
    oldPrice: 1280,                                     // 原價/市價 (純數字，填寫後會自動算出「現省 $390」)
    img: 'https://images.unsplash.com/photo-...',       // 商品圖片網址
    desc: '婆婆媽媽回購第一名！...\n\n可換行寫詳細介紹',   // 點開彈窗後的詳細介紹 (使用 \n 可換行)
    recommend: '👵 初一十五拜拜首選・保證脆甜',           // 卡片上的黃底婆媽推薦亮點標籤
    tagText: '點我看大圖'                                // 卡片右下角提示按鈕文字
}
